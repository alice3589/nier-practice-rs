# nier-practice-rs

NieR:Automata (Steam 版) の練習ツールです。次の 2 つのツールを Rust でまとめて、exe 1 つで動くようにしました。

- [NieR-Automata-Practice-Table](https://github.com/aloyark/NieR-Automata-Practice-Table) (aloyark): ノークリップ・ワープ・各種練習用パッチ (Cheat Engine テーブル)
- [YASM.NieRAutomata](https://github.com/Eveldee/YASM.NieRAutomata) (Eveldee): 練習セーブの管理と読み込み

Cheat Engine と .NET ランタイムは要りません。

## 使い方

```
cargo build --release
target\release\nier-practice-rs.exe
```

起動すると `NieRAutomata.exe` の起動を待ち、見つかったら自動で接続します。
設定 (`config.json`)、練習セーブ (`Saves\`)、上書き前のスロットのバックアップ (`Backups\`) は **exe と同じフォルダ**に作られます (YASM と同じく持ち運びできるようにするため)。

### 練習タブ (Practice Table)

| 機能 | ホットキー | 備考 |
|---|---|---|
| ノークリップ | Num0 | |
| 無限二段ジャンプ | Num. | |
| 無限空中ダッシュ | Num- | CT は `-` キー (VK 189) だったが、README の表記に合わせてテンキー側にした |
| 武器セット切替 | Num+ | 「Num+ で武器セット切替」にチェックを入れたときだけ有効 |
| カスタムワープの有効/無効 | = | |
| カスタム 1 の保存 / ワープ | Shift+C / Z | 位置・向き・カメラを保存する。CE 版と違い、ツールを閉じても `config.json` に残る |
| カスタム 2 の保存 / ワープ | Shift+V / X | |
| Red Dots ワープセット | Ctrl+Shift+D | もう一度押すと解除 |
| A Ending ワープセット | Ctrl+Shift+A | もう一度押すと解除 |
| ワープ先 | 1〜0, Num1〜9, F1〜F7 | 選んでいるセットのものだけ有効。一覧は画面のボタンでも確認できる |

ほかの機能 (ポッドのクールダウンなし、高速溺れワープ、デバッグメニュー無効、どこでもシステムメニュー、スロー歩き関連、パスカルの AI 無効、ポッド A のレーザー固定、ポッドプログラムの書き換え) は画面のチェックボックスから使います。

- ホットキーは初期設定では **ゲームが前面にあるときだけ**反応します (ツール上で文字を打ったときの誤ワープを防ぐため)。設定タブで変えられます。
- ワープは CE 版と同じく、ノークリップを 150ms だけ ON にして座標を書き換えます。もともとノークリップを ON にしていた場合は ON のままにします。
- ツールを閉じると、ON にしたパッチはすべて元に戻します。ツールが異常終了してパッチが残っていても、次に接続したときに ON の状態として認識します。

### セーブタブ (YASM)

1. 「自分の設定」で自分のセーブのスロットを選び、Steam ID・ゲーム設定・キー設定を取り込みます (最初に 1 回だけ)。
2. 練習セーブを用意します。
   - **zip から取り込み**: zip 内のセーブ (235,980 バイトのファイル) を、zip 名のグループとして取り込みます。rar には対応していません。
   - **ゲームのスロットから作成**: 今のスロットに名前とグループを付けて保存します。
   - `Saves\` に `.dat` を直接置いても使えます。直下は `|Default` グループ、サブフォルダはグループになります。
3. 一覧の「→ スロットN」を押すと、自分の設定に差し替えたうえでゲームのスロットに書き込みます。上書き前のスロットは `Backups\SlotData_N.dat.prev` に 1 世代だけ残します。

## CE テーブルからの変更点

CE 版は Auto Assembler でコードケーブ (`alloc` + `jmp`) を作っていましたが、どのスクリプトも即値か分岐命令を 1 か所変えるだけで同じ動作になるため、**同じ長さのバイト列をその場で書き換える**方式にしました (`src/patches.rs`)。

- 例: ノークリップは `mov r13d,1` → `mov r13d,0`、無限ダッシュは `jne` → `jmp`
- 無限二段ジャンプは比較値を 2 → 255 にしていましたが、1 バイトの即値に収めるため 127 にしています (実用上は同じ)
- 書き込み前に現在のバイト列が想定どおりかを確認し、違う場合 (ゲームのバージョン違いなど) は何も書かずにエラーをログに出します
- A Ending の Num8 / Num9 は、README (Castle Skip / Rainbow Road) ではなく実際のスクリプトの割り当て (Rainbow Road / Castle Skip) に合わせています

アドレスやポインタは NAPT 1.2 (ゲーム v1.02 向け) のものです。ほかのバージョンのゲームでは、AOB で探しているパッチ以外は動かない可能性があります。

## 構成

| ファイル | 内容 |
|---|---|
| `src/memory.rs` | プロセス接続・メモリ読み書き・ポインタチェーン・AOB スキャン |
| `src/patches.rs` | CT のスクリプトをバイトパッチにしたもの |
| `src/warps.rs` | Red Dots / A Ending のワープ座標 |
| `src/game.rs` | 座標・武器セット・ポッドなどゲーム固有の操作 |
| `src/hotkeys.rs` | グローバルホットキー (GetAsyncKeyState のポーリング) |
| `src/core.rs` | UI とホットキースレッドで共有する状態 |
| `src/saves.rs` | YASM のセーブ管理 |
| `src/main.rs` | egui の画面 |

テスト: `cargo test` (パッチ定義の整合性・ワープ表・セーブの差し替えと zip 取り込み・自プロセスを相手にしたメモリ操作など)
